# MedLens Frontend

React + Vite + Tailwind CSS + Recharts client application featuring 12 clinical intelligence views:
1. Landing Page
2. Login
3. Register
4. Dashboard
5. Patient Information Intake
6. Upload Medical Report
7. Processing Screen
8. Structured Medical Record
9. Source Verification (Side-by-Side Review)
10. AI Summary (Non-Diagnostic)
11. Report Comparison & Visual Trends
12. Timeline & Audit Trail
